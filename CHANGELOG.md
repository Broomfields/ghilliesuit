# Changelog

All notable changes to this project are documented in this file. Versions before 1.1.0 are documented in the GitHub release notes.

## [1.1.0] - Unreleased

### Added

- Restricted the ghillie suit's enchantability: instead of accepting no enchantments at all, the suit now takes a small set of its own — Swift Sneak on the ghillie pants, Comfort on any ghillie piece, and Poise on the ghillie tunic.
- New enchantment **Comfort** (any ghillie piece): each Comfort-enchanted piece worn extends the active ability's sneak time.
- New enchantment **Poise** (ghillie tunic): enables critical strikes while actively hidden.
- Comfort and Poise are mutually exclusive on the tunic.
